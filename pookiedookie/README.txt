HOW TO CUSTOMIZE

1. Replace images:
   assets/images/

2. Replace music:
   assets/audio/

3. Replace videos:
   assets/videos/

4. Edit questions:
   js/questionnaire.js
   OR
   data/questions.json

5. Edit colors:
   css/style.css

6. Edit final letter:
   js/main.js

7. Add new gallery cards:
   index.html

8. Add more mini games:
   js/games.js

9. Add more easter eggs:
   js/eastereggs.js

10. Hosting:
   Upload entire folder to:
   - Netlify
   - Vercel
   - GitHub Pages

IMPORTANT:
Keep folder structure unchanged.
